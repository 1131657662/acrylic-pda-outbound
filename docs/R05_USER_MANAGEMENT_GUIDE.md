- 编辑取消恢复原按钮焦点；切仓回第一页、清旧数据并丢弃迟到响应，翻页不会应用尚未提交的筛选。错误、空数据、成功反馈和窄屏/低高度布局沿用既有规范。

## 使用方式

1. 有管理权限的人员在当前仓库打开“人员与权限”，按完整登录账号查询；列表仅显示可完整管理的人员。
2. 新增时填写账号、姓名、角色、仓库及初始密码，核对原因和影响后提交。新增/重置密码至少8字符且最多72个UTF-8字节，不强制大小写或特殊符号（2026-09-20源码规则调整，须Web与后端配套部署后生效）；既有密码不会自动改变。
3. “授权与启停”先取得最新资料，保存后相关人员重新登录；“重置密码”单独办理，不修改账号、设备或原作业。
4. 遇到“结果待核对”，保留当前标签页，通过“恢复原人员请求”查询。未查到才补发原请求；不要清存储或新建操作绕过。记录中可查看操作、时间、人员和原因，完整前后授权事实保存在服务端审计。
