# 正式PDA本地扫码作业

2026-09-17，版本`0.2.0-local-work`，沿用V2.3 §8与已确认Q16，承接已完成的身份/领取/资料准备。用户已授权继续。本次完成正式本地扫码闭环，不把尚未接入的云端提交或同步伪装为已确认出库。

- 已完整激活且授权有效的订单可进入独立扫码页。只在前台作业页接收厂家完整广播，扫描键交系统解码；手输通过显式输入框、K1/F1或大按钮加入同一队列。
- Room新增作业头/产品汇总、输入、明细、防重占用、原设备序号与审计。V1升级为V2只增表，已准备的订单/库存/领取意图保留。首次作业初始化固定原计划、原授权起始序号，不重新签发或刷新库存。
- 接收入口64个事件、单消费者，完整事件无防抖无丢弃。输入持久化固定原始文本、规范化条码、来源策略、用户、设备、订单/授权/库存/恢复代次、原周期与时钟信息；失败也占序号。AUTO在通过校验后持久自动意图，MANUAL等待针对当前capture的确认。
- 每次最终保存复核当前身份/48小时/时间可信度、上下文、库存存在、产品、状态/周期、本机跨订单防重及产品/整单计划；有效明细、占用、汇总、审计和输入终态原子提交。整数克精确累加，不按重量大小阻断。
- 错误暂停后续保存，后到输入继续耐久入队。错误确认只绑定当前失败，不顺带确认下一包；已确认或AUTO输入不能清除。未确认手输可明确放弃，已保存末包可填写实物核对原因后撤销，保留原明细、序号及审计。
- 存储失败或入口溢出停扫并明确报告可能未持久化输入。原持久确认保留，恢复查同capture结果，不重复插入或播放旧成功音。重开App恢复队列；改时/设备重启需联网校时。后台/弹窗不继续自动保存，返回时保留未决记录；未决订单不能换单作业。
- 480×800/density240适配，固定候选/确认区与可滚动汇总；成功音只在最终事务提交后请求，错误优先。M71已验证固件指纹仅复用已记录K1/K2/Enter映射，其他设备使用大按钮与标准F1/F2；不声称其他固件或正式App真机已验收。

验证：真实签名包→本地准备→扫码；33项Android主机测试覆盖自动/人工、重复、原周期变化后本机防重、超量、到期/换人、错误队列、撤销重扫、SQL故障回滚/恢复、重启序号、旧数据库升级、输入队列压力、切单期间原输入保留及设备键/广播生命周期；1项模拟器联调执行真实后台→下载→本地作业，并验证页面重建后手输仍须确认、后台广播隔离及重开数据库。尚未用两份真实签名订单完成跨订单防重联调；模拟器测试不代替M71物理扫码、声音/闪存/断电及4条/秒现场验收。

边界：availability仍是准备截点，本机防重不能替代多机全局复核。提交、云端入账/放行、增量同步、召回换机、续期和临时单仍在完整开发范围内；本版本用于开发联调，界面一直标示“本地记录，未上传，不可放行”。
