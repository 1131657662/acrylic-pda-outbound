# 正式PDA准备链路（2026-09-17）

沿用用户已批准的V2.3及继续建设正式PDA链路的指令。本次实现人员登录、设备私钥认证、订单列表/独占领取、下载验签和Room原子激活。正式工程独立于Demo，不修改已验收测试包或其数据。

后端V8增加每份授权唯一的不可变准备包。准备接口在仓库/设备/订单锁内检查当前人员、设备、授权代次及48小时期限，保存原发布计划、按条码排序的库存和冻结可用状态。三个gzip文件分别记录压缩/原文SHA-256、字节数、行数；签名清单绑定授权、设备、人员和服务器恢复代次，原离线授权另校验仓库及权限版本。当前状态仅为准备时截点，不伪造尚未接入的增量游标。原库存内容摘要与原计划摘要必须匹配既有授权，否则拒绝准备。

PDA以HTTPS访问固定服务器（debug仅回环HTTP支持本机联调），Android Keystore保存P-256私钥与AES密钥，登录令牌加密保存。领取前持久化原幂等键/正文，结果未知可以重试或从本机活动授权恢复。设备身份或服务器绑定后不允许无痕切换。退出停止当前人员作业，但保留订单数据和领取意图。

下载流写入私有暂存目录，限制压缩/解压尺寸，逐一核对摘要、行数、字段、条码唯一性、计划/库存/状态关联；限定RS256并核对全部授权上下文、时间和固定48小时。Room事务写完整版本和待确认记录后才可见就绪状态，失败回滚不破坏旧版本。确认只消费已激活资料，服务端核对清单/快照/代次，重复返回原确认时间。重启保留资料和确认队列；跨启动时间不可靠时要求联网校时，不猜测离线有效期。

验证覆盖后端隔离/篡改/固定包/重复确认/到期保锁，Android验签/坏包/重复条码/不完整数据回滚、持久化恢复及时间回拨。构建APK并运行主机测试；只有实际执行的设备或端到端验证才计为通过。

边界：本次不实现正式扫码、结单提交、出库记账、召回换机、授权续期或完整增量同步。页面明确显示“资料已就绪”，不显示可出库或成功放行。
