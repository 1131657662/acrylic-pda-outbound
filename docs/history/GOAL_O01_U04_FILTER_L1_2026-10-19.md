- 第一轮主机 20 项：18 通过、2 个 `WorkAdjustmentTest` 既有 `SQLiteCantOpenDatabaseException`；`TemporaryAdjustmentTest` 6 项通过。原 XML/HTML 在 `unit-first-xml/`、`unit-first-html/`。同根因不机械重跑，不把这批写成全绿。
- 最终 `build-final02-command.json` 对应 Debug、AndroidTest、filter/layout 6 项及 lint，退出 0。新增实际确认消费者后的 `build-test-final03-command.json` 再构建 AndroidTest/lint，退出 0，产品 APK SHA 不变。
- 独立 run914 MySQL/HTTP 上 fixture XML 为 1/0/0/0，实际设备登记、原生登录、签名 TEMP 准备/确认通过。fixture 的 PowerShell native stderr 包装器退出 1，不能改写 XML 事实。最初 fixture 与 Android lint 曾短暂重叠，最终均完成；`private/scheduling-correction.json` 与 `private/scheduling-observed-result.json` 保留，不宣称全程串行合规。
- 初次产品 writer 已保存 27 条 capture/scan、26 VOID 与 1 ACTIVE，此后首次 UI 测试滚动失败。保留原事实，后续显式采用 retained 方法继续验证，没有重新执行创建方法、清库或重绑身份。
- 早期失败分别留在 `filter-first`、`filter-font-1-0`、`filter-font-1-3`、`filter-font-1-00`：scrollTo 导致系统栏裁切，普通 swipe 触发系统 Home，安全中部手势及既有 ScrollView 定位器带来新诊断输入。该轮已有产品写入，不作为“无产品写入”的快速修复豁免。旧失败计数与日志不清零。
