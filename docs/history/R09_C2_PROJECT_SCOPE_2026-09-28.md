| 入口 | C2待接生命周期与验收重点 |
| --- | --- |
| HTTP / Spring Session JDBC | 在SessionRepositoryFilter之前接纳，持操作租约至最终Session保存结束；GET、CSRF和异常响应也可能写Session，不能只拦业务POST |
| PDA登录、刷新、退出 | challenge/session/last_seen/审计写均受准入保护；保留原权限、设备、签名与CSRF校验，受控认证不得暗中发放新作业资格 |
| Worker poll / 提醒sweep | 覆盖claim、执行、独立续租、完成、失败及收尾；维持既有Job代次校验，与关闭并发时不能漏登记或提前释放 |
| ImportFiles / SubmissionFiles / ExportFiles | 文件写前有操作租约；失败路径、临时文件、尚未入DB引用的文件活动同样可排空 |

| ExportRendererProcess / 报告子进程 | 父操作持租约到实际退出已确认；未知退出保持关闭。Windows Job能力复用，Linux隔离按容器/部署证据另验，不互相外推 |
| Flyway / BootstrapAdmin | 显式独立迁移/初始化准入；普通实例缺控制记录不得自建NORMAL，迁移不能与业务写并行 |

连接层、请求层、任务层应使用同一固定实例身份，维持coordinator→writers→server_state→业务锁顺序。不得用业务service内一次文件检查替代外层生命周期保护；UNKNOWN事务/连接/子进程状态不能因finally、回调返回或close成功而自动视作排空。

## 4. 独立时间盒和验收建议（尚未执行）

建议先用一个独立评估时间盒完成入口清点、C1依赖裁决和可复验设计；实施按HTTP/Session、Worker/文件/进程、初始化/组合三段划分。每段独立实现提交与验收记录，未满足标准就保留断点，不承诺一次时间盒结束全部生产入口接线。重要节点可安排独立审查，本次仅作者整理。

| 验收组 | 建议通过标准 |
| --- | --- |
| 正常路径 | 非空独立MySQL + 真服 + 真HTTP验证允许态请求、PDA认证和CSRF/GET最终Session写；不绕过已有权限/设备守卫，不新增作业放行 |
| 关闭竞争 | 可控屏障分别卡住请求/Session尾部、事务、claim/续租、文件写和渲染进程；关闭后拒绝新普通入口，已接纳者完整登记且有实际完成/排空证据 |
| UNKNOWN与异常 | 模拟提交丢响应、连接/文件异常、进程未知退出；租约/毒化保持，不能被后来成功close或错误码降级洗掉；未知完成不得宣称已安全释放 |
| 重启/权威缺失/DB回退 | 旧实例、控制原件缺失/不一致、恢复DB落后时拒绝普通写；不得自行初始化NORMAL或重造原身份 |
| 入口完整性与数据守恒 | 逐入口动态覆盖表和退出证据可审计；原ID/回执/事实不可变项逐值核对，业务变化仅限已授权操作；迁移与业务不并发 |
| 默认关闭与组合限制 | 默认配置/生产能力保持关闭；C1未满足不得记为NORMAL全链通过。Windows/Linux、Android/现场和部署证据分列，单测/静态扫描不代替组合验收 |

若入口遗漏、租约层级或NORMAL协议出现未定语义，停在可审查设计与失败证据处交回决策。发现新真bug按项目纪律停报，不以接线名义扩大修复。
