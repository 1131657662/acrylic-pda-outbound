## 3. G1：停止保全的耐久性——**单次通过，可重复性未建立**

首次运行（干净设备）两阶段各 `OK (1 test)`／`numtests=1`，测试自身打印：

```text

R06A11_G1 phase=2 items=2 stopEvents=1 queueState=ACTION_REQUIRED autoRetry=0
R06A11_G1_RECONCILE state=ACTION_REQUIRED autoRetry=0
R06A11_G1_RESULT all four assertion groups passed in a fresh process
```

| 断言组 | 结果 |
| --- | --- |
| ① stop 行与签名仍在、`evidenceId` 一致 | 通过 |
| ② `local_draft_stop_item.rawBytes` 逐字节相等 | 通过（`items=2` 两阶段一致） |
| ③ `LOCAL_EVIDENCE_STOP` 事件数不变 | 通过（`stopEvents=1 → 1`） |
| ④ 队列不自动续传 | 通过（两阶段 `ACTION_REQUIRED / autoRetry=0`） |
| (C) 三步身份切换 | 通过（置 `autoRetry=1` → `sessionChanged` 暂停 → 冷启动后仍暂停 → `reconcile` 不复活） |

**第二次运行失败（必须记录）**：在"已被 seed 过"的设备上重跑，`phase1`／`phase2` 均 `FAILED`（`failureMarker=True`、`numtests=1`）。**根因是测试自身不幂等**——合成事件用固定主键 `r06a11-event` 直接 `INSERT`、插入前未删除；而 `-no-snapshot-save` **只禁用快照保存、不阻止 userdata 落盘**，上一次运行留下的同一主键触发 UNIQUE 约束。**⇒ 首次 PASS 属"干净设备状态依赖"，G1 可重复性不成立。**

**已做的离线修复**：`insertSyntheticStopEvent()` 插入前先 `DELETE FROM temporary_event WHERE id='r06a11-event'`（并注明理由）。G1 其余直接 `execSQL` 已复核：`seed()` 本身"先删后插"幂等，队列那条是 `UPDATE`（天然幂等）⇒ 无其他非幂等写入。**该修复尚未在设备上重跑验证。**

## 4. 未验边界（不得被本记录覆盖）

1. **真实竞态**："扫码写"与"停止写"并发——device 层未验；单测层为真实 Room 但**顺序交织模拟**＋一条**真实多线程串行化/幂等探针**（非调度竞态）。
2. **真机重启**：G1 用的是**模拟器上真 `am force-stop` + 冷启动**，**非真机重启**；真机条件属 C 档。
3. **"停止动作由产品在设备产生"**：device 层用的是 **raw-SQL 合成行**，未走产品路径（产品路径需服务器签发的临时作业授权包＋已配对会话，仅存在于单测源集）。
4. **对端 POST 计数**：G1 **未断言**"0 个 POST"（无服务器接入，无网络观测）；只断言**自动续传被禁用**。
5. **真实会话切换/配对**：`LocalDraftQueueGuard` 由**手写会话 JSON** 驱动 ⇒ 只测 Guard 逻辑，**真实登录/配对流程未走**。
6. **G1 可重复性**：缺陷已修、**未重跑**；G4-2/G4-3 亦均**单次通过**，重复运行未验。
7. **设备侧验签**：签名行为**结构性占位**，**未做**设备侧验签，任何表述不得暗示已验。
8. ② 的**坏原件/坏请求/坏回执专项设备用例**、⑤ 的**丢回执专项设备用例**均未做。
9. `A1.4 FORMAL 来源夹具`（5 轮未成）**未纳入**本批。

## 5. 口径声明（写死）

- 停止族数据集为 **raw-SQL 合成行**（`R06A11SyntheticStopDataset`），**非服务器签发事实，永不上传**。
- `local_draft_stop_signature` 行为**结构性占位**，**永不构成有效签名**；签名有效性与"停止由产品产生"由**单测层**覆盖（两层合并，不是一层替代另一层）。
- `LOCAL_EVIDENCE_STOP` 事件为**合成行**（`captureId=NULL`），**只用于证明"事件数在真进程死亡＋冷启动后不变"**。
- 身份切换为**手写 JSON 输入**，仅测 **Guard 逻辑**。

## 6. Harness 硬化（本批副产物，均在 `.local`，不提交）

1. **禁止字符串/行修补**，改整文件重写；**禁止把长逻辑塞进一次性 inline 命令**，多步流程一律写成 `.ps1`。理由：本批 5 次失败全来自 inline 修补/解析错。
2. **runner 组件名修复**：`pm list instrumentation` 的字面前缀 `instrumentation:` 必须剥离；否则 Android 找名为 `instrumentation` 的包 ⇒ `INSTRUMENTATION_FAILED`（1.8 s、零输出）。现加**启动前格式自检**，不合规**拒绝启动**。
3. **假通过漏洞修复**：判据由 `OK (`（会被 `OK (0 tests)` 命中）改为 `OK \([1-9]\d* test` ＋ `numtests ≥ 1` ＋ 显式排除 `OK (0 test` ＋ 无失败标记；**并以一次故意空跑反向验证**（不存在的方法 ⇒ `gate=FAILED`、`GUARD-VERDICT=AS-EXPECTED`）。
4. **空报表守卫**：采集到的测试自报行数为 0 ⇒ 直接判 FAILED（该守卫曾在真实缺陷上生效一次）。
5. **PowerShell 大小写不敏感**导致的参数覆盖 bug（`$phase1` 覆盖 `$Phase1`）已修，并**打印实际下发的 `-e class`**。
