1. 先过完整应用冒烟（准入组件实际启用、过滤器顺序与分派范围以**注册配置＋运行轨迹**证明、Session 保存期间根存活且连接属该根、请求后 `leases/` 清空、清理已禁用生效、P5 进程记录持锁、无未声明自动提交写），再进 IT。

3. **拒绝断言按阶段区分**：
   - **接纳前拒绝**（S2/S7/S10/S11/S12 等）：断言**零业务写、零根登记、零 P5 租约记录**；
   - **登记后撤销**（S13-③ 后探针发现孤儿、S17 效果门、S18 探针内部死亡）：断言**保留完整轨迹**——根与 P5 租约记录确已建立、随后被退役或围栏、**零业务写**、并给出 P5 目录与围栏记录的核对结果；不得笼统写“未登记根”。
4. **必须直接覆盖**：S13-①（登记与接纳并发且**检查前移**）、S13-③（探针内部死亡）、S15（异步未结束的线程复用）、S16（INITIAL 关闭意图合法路径）、S17（效果门）、S18（探针内部死亡后的孤儿可见性）。
5. C1（`C1InitialNormalHttpIT`）与 105（`RecoveryAdmissionEntryChecks`）既有断言全绿是 B1 前置；既有 14 个 Recovery 单测保持绿；`RecoveryAdmittedDataSource` 旧语义逐字节保留（仅不再 `@Primary`）。
