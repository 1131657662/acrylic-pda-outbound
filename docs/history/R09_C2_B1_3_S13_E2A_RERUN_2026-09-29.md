## 4. 供给配方（写进工具，供后续实验舱复用）

1. **binlog 必须在**：`E2aCrossSourceProfile` 断言 `@@log_bin == 1`（"Binlog must remain enabled"）⇒ 不能用 `--skip-log-bin`；并需 `--log-bin-trust-function-creators=ON`（触发器创建）。
2. **账号要有 `PROCESS`**：入口检查读 `information_schema.INNODB_TRX`（否则 `BadSqlGrammarException`，本机实测）。
3. **`--skip-name-resolve` 下要有 `root@127.0.0.1`**：`--initialize-insecure` 只建 `root@localhost`，TCP 连不上 ⇒ 管理/关停需要显式环回 root 号（本机实测：不加则 `mysqladmin shutdown` 失败）。
4. **IT 走 `integrationTest` 任务**：`server/build.gradle` 的 `test` 任务显式 `exclude '**/*IT.class'`；`--tests <IT>` 配 `test` 会得到 "No tests found for given includes"。
