## 2. 硬约束（不得因本切片放松）

1. **默认关闭**：S1–S4 完成后两个开关仍为 false；不得因内部测试通过而开放放行能力。
2. **锚点政策暂缓**（用户 2026-09-29 裁定）：`RecoveryFenceAuthority` 的锚点秘密保管/轮换未定；**S1–S4 不得把 F5/孤儿扫描当作防伪依据**（[G0 设计 §455](R09_C2_G0_DESIGN_2026-09-28.md) 第 3 条）。
3. 不运行、不验收恢复链业务（投影推进、关闭链 NORMAL 登记、真实关闭权威创建/切换）——那些属 **B9**。
4. 移出范围（B1 不含）：`jobs/*` 与 Worker、各文件入口、渲染子进程、Flyway 迁移准入、`BootstrapAdmin` 准入、Spring Session 过期清理、生产释放与孤儿解除。
