## 3. `E2aHandoverHttpLayerIT`（642）受阻的精确证据

断言 `assertThat(status).as("① switch off must be an absent route").isEqualTo(404)` 实得 **-1**，而源码里 `status` 的取值是
`int status = session.login(outsider) ? session.postHandover("{}") : -1;`
⇒ **-1 表示 `session.login(outsider)` 返回 false**（探针连会话都没建立起来），根本没有发出那次 HTTP 请求，因此这条"开关关闭时路由应 404"的断言语义**未被检验**。定性：**harness 登录/会话前提未满足**（该 IT 依赖的用户/凭据供给），非产品判定，也非 B1-3 回归。
