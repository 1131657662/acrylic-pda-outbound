## 登记一台PDA

1. 仓库管理员登录Web，选择设备归属仓库，在侧栏打开“PDA 设备管理”。账号须具备`device:manage`和该仓库权限。
2. 原PDA核对安装包配置的环境及地址后点“开始登记”，把屏幕上的8位登记码告诉管理员。PDA会自动上传公钥并证明持有私钥，无需搬运长文本。
3. Web在“短码配对登记”输入登记码，查找并核对型号、申请时间及仓库。填写编号和名称：编号只含字母、数字、下划线、短横线，最长40位；名称最长100字。勾选核对，点“确认登记意图”，再发送给原PDA确认。
4. 页面显示“等待原PDA核对并确认”时，设备尚未启用。原PDA核对仓库、名称和编号后确认绑定；Web点“核对绑定结果”，完成后设备进入列表。已有身份详情仍可查看。
5. 原PDA自动保存身份后使用获授权人员账号登录。登录需要账号密码和本机私钥证明，配对不是人员登录。

登记码有效10分钟，两端须能访问同一后台，不要求同一Wi-Fi。当前本机APK使用18083回环地址及USB转发，不是异地服务地址。已绑定PDA沿原身份使用；“高级公钥登记”及PDA高级维护保留作维护入口，普通操作不使用。

设备编号与公钥全局唯一。登记到其他仓库、重新安装App或丢失私钥时，不通过改编号绕开已有订单占用；当前页面没有迁仓、换密钥、删除设备或接管订单入口。

## 停用和重新启用

在设备行点“停用”或“启用”，核对设备及操作影响，填写原因并勾选确认。当前列表按仓库每页50台，最近联网时间仅表示最后一次联网记录。

停用会阻止在线认证并作废已有登录会话；离线PDA不能即时收到后台变化。重新启用须重新登录，旧访问/刷新令牌不会恢复。两种操作均保留订单占用、原离线凭据与截止时间、本机资料；不能用停用再启用让第二台PDA抢走订单。

操作回执反映那次操作的结果。若另一管理员后来做了新操作，重试旧请求只取回原回执，不反转最新状态；以刷新后的设备列表核对当前状态。遇到设备版本变化，关闭确认窗口，刷新后重新核对再操作。

## 连接中断或刷新页面

短码确认发送前保存原申请、正文、请求键和恢复代次；失败后保持当前标签页，刷新并点“恢复原配对确认”。同一账号和仓库恢复，存储失败不发送，错误回执不会显示成功。原PDA使用“刷新／恢复原请求”，已完成结果在短码到期后仍能恢复。取消/过期及信息变更的处理见[恢复说明](PDA_PAIRING_REGISTRATION_GUIDE.md#中断与恢复)。

以下“恢复原设备请求”专指高级登记与启停：

发送前，页面先将原请求保存到当前浏览器标签页，按人员和仓库隔离。存储失败时不发送。网络失败或回执不匹配后保留原内容、请求编号和服务器恢复代次；表单不能改成另一项操作。

保持同一标签页，可刷新或暂时离开后返回“PDA 设备管理”，点“恢复原设备请求”，再点“重试原设备请求”。页面不会自动重发；重试成功核验后才清除记录。登录失效时须同一人员重新登录；权限撤销或服务器恢复代次变化时保留原请求并联系管理员核对。

关闭整个标签页后不保证能恢复此入口，应先查设备列表和操作结果，不能因没看到响应就换编号重做。浏览器仅保存设备登记/启停内容，不保存设备私钥或登录令牌。
