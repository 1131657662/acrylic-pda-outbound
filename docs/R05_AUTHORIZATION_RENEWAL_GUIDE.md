# R05 受控授权续期交付记录

日期：2026-09-18。范围是同一PDA作业的联网授权续期，不包含增量同步、换机、出库更正、任务调度或公网部署。

后续同步、任务和提醒已接入，当前接续以[R05验收状态](R05_ACCEPTANCE_STATUS.md)及[开发进度](DEVELOPMENT_PROGRESS.md)为准。下文计数和未完成项是本子项当轮记录；续期真实PDA的丢响应/跨进程恢复、到期及未决输入场景仍须独立补验，不能用普通同步通过代替。

## 已完成

- 服务端新增 `POST /api/v1/pda/assignments/{id}/renewal`，并保留 `/renew` 兼容入口。当前在线会话须仍绑定原人员和原设备，续期正文绑定原授权ID、订单、订单修订、授权代次和本机未决输入数。
- 续期在事务内锁定订单和授权，要求作业仍为 `ACTIVE`、订单仍为 `ASSIGNED` 且没有冻结/上传事实。召回、提交、停止、账号或设备版本变化、恢复代次变化、未决输入和幂等正文变化均拒绝，原占用与本地资料保留。
- Flyway V19 为 `offline_authorization` 增加同一作业内的授权序号及替代关系。新授权固定48小时并重新签发RS256 JWT，绑定原作业上下文和前一授权ID；旧授权的签发时间、有效期和签名内容不改写。
- 同一人员和续期路由的 `Idempotency-Key` 重试返回第一次产生的授权及签名；审计写入 `PDA_AUTHORIZATION_RENEWED`。旧授权撤销和新授权插入、幂等回执、审计在同一事务提交。
- Android Room 由7升8，保存授权历史JSON；联网响应先核对作业、原授权、快照摘要和48小时签名，再原子替换本机当前授权。失败不会覆盖原作业资料。
