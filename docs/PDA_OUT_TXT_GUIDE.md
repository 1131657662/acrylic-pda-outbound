# PDA 直接导出 out.txt 点按教程

本教程对应“正式订单简单文本导出”功能；安装包和验证范围见[看板](ORCHESTRATION_STATUS.md)。这里的文件可以直接交给原来的读取系统，不需要 Excel 转换或文件解密。身份核验用来限制谁能取回原记录，与文件加密是两件事。

## 一、已经扫完的正式订单，从哪里进入

1. 打开 PDA 应用，点主界面顶部的 **数据**。
2. 点 **已验签完成历史**，找到需要的原订单并打开。
3. 如果看到“回执已验签”，在该页面向下找到 **只读应急导出（生成 out.txt）** 并点它。按钮在“查询原提交结果”后面、“原批次与诊断详情”前面。
4. 进入“离线取回本机记录”页面，按第二节核验本人身份。核验后会优先选中刚才打开的原订单；仍要核对车号和订单号。

另一条入口：主界面顶部 **数据 → 只读应急导出**。从这里进入需要在核验身份后自己选订单。

如果打开应用停在“人员登录”，可直接点该页的 **只读应急导出（预置救援凭据）**；已有凭据时不必先正常登录。首次预置本人凭据仍需原操作员联网登录核验，按下一节操作。

## 二、第一次使用：设置本人解锁方式

本机已有本人凭据时，跳到第三节。身份下拉框空白表示尚未预置可用凭据，不是订单已经丢失。

1. 确认 PDA 能连接测试后台，并以该订单的**原操作员**正常登录。不能随便换一个人代替。
2. 在导出页点 **首次设置或撤销本人应急解锁**。
3. 在 **手工设置应急解锁口令（备用）** 下面输入自己保管的口令：16–128 位无空格 ASCII 字符，不使用人员姓名或简单序列。
4. 点 **联网核验并保存解锁方式**，等待页面明确提示设置成功。
5. 点 **返回** 回到导出页。不要把真实口令发给开发人员或写进教程、日志。

也可使用页面上的“安全生成并独立保管应急解锁方式”；该方式还需要保存本人凭据卡、重新选择原卡回读、确认设备外保管后再设置，不能只点生成就离开。使用手工设置路径不需要生成文件解密材料。

如果原操作员无法联网核验，也没有预置本人凭据，需按已有主管救援流程取得有效原授权；不能通过自填姓名或跳过核验来导出。

## 三、选择订单，直接保存文件

1. 在 **已预置的只读身份与范围** 下拉框选择本人身份。
2. 输入第二节设置的 **应急解锁口令**，点 **核验身份并选择原记录**。如果之前选择安全生成的本人凭据卡，也可点 **选择本人凭据卡解锁（无需转录口令）**，选原卡。
3. 在 **第2步：选择原记录并核对快照** 的下拉框选择要导出的订单。
   - 按本机记录时间从新到旧排列，时间显示为北京时间。
   - 每项显示来源、日期时间、车号、业务订单号和完整记录编号，多行展示。
   - 正式订单的“资料保存”是本机保存资料的时间，不是服务器确认出库的时间。
   - 一页没有找到时，点 **下一页原订单**。不同车辆或订单不要只看 UUID 来猜。
4. 点 **读取一致原件快照**，核对有效包数、VOID、处置、未决、失败数量。这个动作不会补造提交或改变原单。
5. 在 **第3步：直接保存 out.txt，无需转换或文件解密** 下点 **直接导出 out.txt（简单格式）**。
6. Android 会打开系统“保存”窗口。选择自己能找到的目录，例如“下载”；保留文件名 `out.txt`，点系统的 **保存**。若目录里已有同名文件，先确认是不是需要保留的旧文件，可改成带日期和车号的 `.txt` 文件名再保存。
7. 回到应用，等待出现 **out.txt 写入与回读一致**。没有这句话、取消了保存、写入失败或回读失败，都不能当作已导出成功；原记录仍保留。
8. 用 USB 连接电脑，在 PDA 的 USB 选项中选择 **文件传输**。在电脑里打开刚才选择的目录，把文本文件复制到电脑。
9. 直接交给原系统读取。用文本编辑器查看时选择 **GBK/简体中文** 编码；不需要运行解密或 Excel 转换工具。

**这条流程不需要点**“安全生成解密材料与加密包”“使用已有口令生成加密包”“第4步：选取目标写入回读，再到电脑核验”或“导入电脑返还的原批次签名回执”。这些属于高级原件保全或业务回执中转。

## 四、文件里有哪些内容

每行一条有效扫码记录，五列按下面顺序排列，无表头，列之间是 TAB：

`型号 → 条码 → 原始重量 → 可信原操作员姓名 → 北京时间`

使用 GBK 编码、Windows CRLF 换行，按原扫码序号排序。VOID 或已被处置排除的包不计入。文件不含车号表头，保存后请按所选原订单归档，避免不同车辆的 `out.txt` 混在一起。

缺少可信原操作员姓名、时间无效、字段含 TAB/换行或不能以 GBK 编码时会拒绝生成并显示原因；不会自填姓名或把原始重量改成估算值。文本导出是只读取回记录，不代表补传成功、确认出库或允许放行。

## 五、只有 sku.txt，准备新扫一车货

这是“独立采集”来源，和上面已经存在的正式订单不同。资料入口是：

1. 主界面顶部 **数据 → 独立sku资料预检与启用**。
2. 点 **选择sku原文件并预检**，选择原始 `sku.txt`，先处理页面列出的错误或重复。
3. 预检合格后点 **启用预检资料，仅供新独立任务**。
4. 点 **独立任务计划与原请求**，按原身份、可信期限和待对账要求建任务后采集。

**本次简单 out.txt 实现仅覆盖正式订单。TEMP 临时单及“导入 SKU → 独立扫码 → 直接 out.txt”还没有接入这个简单格式，不能按第三节承诺可导出。** 独立记录保持“待主管对账”，已有高级保全能力也不等于正式出库结果。不要为了导出把独立任务冒充正式单。

## 六、常见卡点

| 看到的情况 | 怎么处理 |
| --- | --- |
| 原订单打开后只有“回执已验签”，没有导出按钮 | 核对是否已安装看板登记的本次测试候选；老安装包没有补上的完成页入口。可先从“数据 → 只读应急导出”进入。 |
| 身份下拉框为空 | 按第二节，由原操作员联网预置本人凭据。未预置时不能用空列表判断没有订单。 |
| 下拉框没有预期订单 | 先核对所选身份和本机设备，再翻下一页；其他人的订单不应自行扩大读取范围。 |
| “直接导出”按钮不可用 | 先点“读取一致原件快照”，再看提示原因。TEMP/独立来源或缺少可信原姓名等条件不能强行生成。 |
| 取消保存、USB 拔出、空间不足或回读不一致 | 不使用不完整文件，保留原单，重新选择可写且可读的保存位置。 |
| 电脑打开中文乱码 | 按 GBK/简体中文编码重新打开原文本；不要把乱码另存覆盖原件。 |
