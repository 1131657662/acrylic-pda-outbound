## 本子项完成标准

1. Java独立读取Python实际生成的规范UTF-8原件；严格字段、64KiB界限、UUID/时间/仓库、原命令摘要、bootstrap及全历史链、CAS和阶段转换均验证。配置安装身份/完整恢复集一致；重复commandId、未知文件、半提交、错指针拒绝且不修改原件。
2. 必须显式提供authority/恢复集之外的可信checkpoint；验证其位于完整链中，整体目录回退也拒绝。重启读取不生成身份/记录，不以current本身作为可信锚点。
3. 路径拒绝父级symlink/junction/reparse、硬链接、Windows别名/ADS及非本机固定盘；恢复目录与authority双向互斥。受保护父目录/ACL为运维信任前提，不声称抵御管理员同时篡改authority与独立锚点。
4. Java/Python使用coordinator.lock第0字节长度1的排他锁。同进程先串行化再打开描述符，防止POSIX关闭其他描述符释放已有锁；双进程握手验证两个方向、正常释放和进程死亡。旧POSIX flock写者必须先退出；不热切换锁协议。Windows本批实际测试，其他平台按实际环境标记，不冒充通过。
5. 自审修复、定向/相关全套及Python→Java真实原件消费留证；测试失败/原件保留。本子项没有DB/schema/HTTP/Android调用点，不能以通过声称共享门禁、数据库恢复、APK或发布通过。

## 实现选择

消费者分为规范字节编解码、字段/转换校验、路径与受控锁、全链读取；避免复用其他业务协议的数字或JSON排序规则。只读结果保留完整范围/证据摘要；所有关闭阶段普通写与本地删除均为false。下一子项将同一锁租约接入事务/请求/文件写者并验证排空；一次读取不能替代事务屏障。
