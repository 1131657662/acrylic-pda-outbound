## 已完成前置：已追踪文件写者退出

本范围当批已验，见[退出确认验收](../../history/R09_PROCESS_DRAIN_ACCEPTANCE_2026-09-26.md)。下方完整树限制仍有效。

完成标准：现有导出取消、超时、丢租约时，发出kill后必须等待实际renderer和已记录子进程退出；中断不得跳过等待，恢复线程中断标志；未能确认退出明确报错并阻止该实例继续生成导出。测试不能在render返回后额外等待再宣称排空；保留测试原件/失败日志。

现有 `ExportRendererProcess.stop` 只异步kill，没有等待；原测试在返回后额外等待5秒，无法证明返回时排空。分离已观察进程的终止等待，并以真实父/子进程验证返回时两者都停止；延迟OS退出和超时用边界进程替身验证。

该修复只证明已观察的进程退出。父进程突然死亡前产生、又未被追踪的孤儿仍需要OS进程组/Job/cgroup隔离或写者独立租约，不能以ProcessHandle采样宣称完整进程树隔离。完整共享门禁验收须覆盖该缺口。

## 接续完成标准

Windows Job与Linux隔离用户cgroup当批结果见[容器验收](../../history/R09_PROCESS_CONTAINMENT_ACCEPTANCE_2026-09-26.md)。Linux每次导出独立容器、项目服务实际停止与完整共享排空仍未完成。

1. **接纳/排空**：库外租约先于DB/身份锁，API包括session GET、Worker调度/任务、文件及迁移持有到实际提交/子进程退出。关闭命令开始后拒新写并等待已有写者；失败状态不释放为NORMAL。盘点全入口和后台库写者。
2. **固定身份/DB桥梁**：原安装身份、UUID控制epoch/revision/摘要与业务DB投影一致；numeric epoch仅作明确映射，原签名/原请求/回执不改写。缺失、回退、旧实例和错DB拒写。
3. **受控阶段**：认证/证据能力按已定范围接入，QUIESCING与RECOVERING区别；NORMAL初始化与PREPARE→DB→COMMIT原命令重试分开验证。生产释放/七类决定入口保持不开放。
4. **当批验证**：实际外部原件→Java→非空隔离MySQL/真实HTTP，旧请求/Worker及独立文件写者跨切换竞争；事务回滚/丢响应/进程退出失败/restart等反例留证。独立消费者与作者自审分开记录；生产、现场、长期部分继续未验。

## 当前子项：跨进程写者租约

完成标准：两个Java进程可同时持共享租约，Python推进关闭阶段必须获得同一字节的独占锁；任一写者仍在则原命令/指针不变。最后租约释放或进程死亡后可按原命令重试。Java嵌套、跨线程关闭和反复读取控制记录不能提前释放POSIX锁。坏/缺失/替换/别名文件失败关闭，所有失败原件保留。

方案比较：coordinator.lock不同字节会被POSIX同inode任一描述符关闭影响；长持协调独占锁又使所有读者和写者串行。因此使用永久独立writers.lock字节0、长度1，Java按原文件系统身份仅一个描述符及引用计数（包括目录改名后的同inode），Python只承担控制侧独占。锁序固定coordinator→writers→DB。协调短锁内验证当前原件，再取得共享租约；受控推进先协调锁后独占写者锁，不等待时返回WRITERS_ACTIVE，无半写入。

新建authority追加writers.json（安装ID、原identity摘要及原锁文件系统身份）与writers.lock；旧identity/原命令/历史/回执不改。两文件必须成对且精确格式。旧authority仍可只读，但没有协议文件时拒绝任何推进/修复；没有自动迁移或重启补文件，停机迁移需后续独立实现。旧消费者因未知文件拒绝新authority，禁止默默混用。

本子项不授NORMAL能力；共享租约只证明已接入写者仍持有本机锁，不能证明DB连接/文件子进程已排空。API/事务接线、关闭意图防新写与DB投影桥梁作为下一子项继续，不能将本层通过写成门禁完成。

## 当前子项：真实事务生命周期

完成标准：事务原控制快照在实例构造时固定，事务前在协调锁内复核完整快照并取得共享租约；之后才打开DB事务，直到提交/回滚、同步回调、连接清理全部结束才释放。外部控制已变、缺失、外层事务存在时，在回调与DB连接之前拒绝。afterCommit尚未返回时控制命令仍须拒绝，SQL异常回滚后可按原命令推进。

采用独立RecoveryLeasedTransaction组合DataSourceTransactionManager/TransactionTemplate，先不自动替换应用事务管理器。全局DataSource装饰涉及Flyway初始化/受控认证/只读会话/原实例桥梁，不能在缺投影校验时无差别切换。此组件只负责生命周期和固定快照，调用者仍须在同一DB事务内先验证业务能力及DB投影；不注册生产bean/路由，不授普通或证据写权限。真实独立MySQL验证与既有HTTP导出回归分别记录，不冒充API共享接线。

补强：提交/回滚结果UNKNOWN保留租约并毒化实例，直到进程被隔离；不能把提交异常翻译成普通回调错误再声称已回滚。禁止已有外层事务及租约内的REQUIRES_NEW/NOT_SUPPORTED挂起，防独立内层事务的不确定结果逃逸。Spring事务同步回调/清理结束与物理连接死亡是不同证据；隔离验收另查测试进程退出后实际MySQL连接/活动事务为零。
