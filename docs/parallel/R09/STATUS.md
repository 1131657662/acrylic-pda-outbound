- 首次恢复结构字符串对比拒绝等价的显式utf8mb4声明；记录数与内容校验和相同。加入仅此等价声明的规范化及“排序规则/长度/NULL改变仍拒绝”的测试后，在新专用实例完整重跑恢复通过。
