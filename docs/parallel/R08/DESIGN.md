## 决策与边界

- 独立 Java21 Gradle 工程 `report-rendering/`；POI SXSSF / 固定 HTML + Playwright Chromium，对齐 V2.3 §7.3～7.5。没有 Spring、数据库、服务或共享构建依赖。
- 接受不可变的模块自身快照，固定成员列表顺序、每单 revision/resultVersion、来源、截点、生成时刻与期间；不自行查询“当前”。快照一致性和授权由后续上游负责。
- 本次提供确认实绩/指定版本净结果文件。计划单、待审核预览、历史文本导入及 MOVEMENT_DATE 模板不在本子项中，不能把缺失实绩填零后冒充确认结果。
- Excel：订单汇总、产品汇总、原始扫码明细、调整凭据、当前有效明细、异常记录与快照说明。逐包原始事实不变，净值零贡献行在输入保留，输出有效明细只列 count=1。
- 精确重量仅以整数克字符串输入、BigInteger 求和；Excel 可安全显示范围内写数值，所有重量另有精确 kg 文本列，超15位克数时数值列留空。条码/代码/车柜号/序号/所有外部文本写 STRING，不生成公式或超链接。
- 原始行必须已按每单 orderScanSeq 严格递增排列；不自动修复乱序。多单按固定成员列表顺序；多原设备必须有 VERIFIED_HANDOVER 引用，单凭设备序号、时间或上传顺序不可推断。生成器检查引用及顺序结构，不验交接凭据真实性。
- 本模块不是更正引擎：上游提供原始、已批准调整效果及完整净结果；生成前逐包和抬头核对一致性。不接库存流水、不批准更正、不生成结果版本。
- 默认 SHIPMENT_DATE_NET：由原确认时刻在 Asia/Shanghai 的日期归属，跨日调整仍落原出库日；范围外原订单拒绝。ORIGINAL_CONFIRMED 仅接受 version1 无调整快照。
- R06临时来源、R07交接/调整模型均属接入提案；未具备真实源时只用 TEST_SAMPLE，文件各表/每页显式标记测试样例。
- PDF A4，嵌入固定中文字体，重复表头、自动分页、合计、签字栏、页码；数据 HTML 转义，浏览器不访问网络/任意本地文件，禁 JS。
- 严格输入限额、临时文件独立目录、失败不发布半成品；大规模 Excel 流式写表。输入快照仍驻内存，PDF整体渲染有独立规模上限，不能声称无限量支持。

## 验证计划

模块单测及真实生成文件重开检查：空集合、多产品 A/B/A、跨设备局部序号碰撞、重复/乱序、前导零、长条码、整数克精确求和/超Excel精度、跨日退货/重量调整、抬头调整、净结果缺失、恶意文本、非法控制字符、跨表、跨页和大数据量。PDFBox渲染到PNG后人工视觉核查中文、长文本、表头、合计、页脚；Excel读取原生单元格类型并预览代表工作表。

不使用数据库、业务服务、公网或PDA。所有缓存、浏览器、构建和证据留在任务 worktree 内。本轮不改公共路线/总进度，不提交/推送/合并/发布，除非另获指令。
