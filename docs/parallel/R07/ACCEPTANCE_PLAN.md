# R07验收方案（全部待实现后执行）

本文件是设计阶段的可判定验收场景，**未执行任何R07业务测试**。本轮实际验证仅文档/源码交叉检查，见[进度](PROGRESS.md)。本机单元/数据库集成、Android主机、浏览器/模拟器、M71、异地HTTPS、恢复演练及生产验收分别记录，不复用历史通过数。

## 1. 夹具与判定方式

使用隔离库、独立端口/模拟器和合成订单，不访问原目录真实业务数据。A/B/C各有独立设备/人员，A和B都有deviceCaptureSeq=1、localSeq=1；B另有独立待审/未知任务。O1为300+包混合产品订单，包含失败、放弃、撤销和未决输入；O2用于跨单抢包。PDA及PC各准备autoDeduct开/关成功单，原包cycle=1。

每次场景记录具体代码提交、契约/数据库/Room/APK版本、前置数据、命令ID和hash、请求结果、数据库前后事实/账务/占用、签名回执及本地重开结果，去除凭据。并发使用可控屏障，让两事务确实到达竞争点，不以手动先后点击冒充并发。故障注入位于明确事务/文件/网络边界，失败后验证全不成及同请求恢复。

共同判定：原正文hash/原回执/原来源/原序号不变；同包有效占用≤1、同包同周期dispatch≤1、每更正行effect=1、每原流水完整反向≤1、每原dispatch周期转换≤1；净结果可由原事实+effects复算，ledger可独立复算；签名/权限/恢复阻断无绕过。
