# R04 辅助页面实施与验证

日期：2026-09-18。范围为现有 Web 库存、导入、发货代码、规则、设备及 PDA 登记、登录、设置。本文记录开发验证，不表示完整系统验收或生产上线。

## 实际完成

- Web 库存、导入记录/明细、库存版本/差异、产品对应历史、规则及设备列表沿用服务端真实游标，增加上一页、当前页及失败原游标重试。没有编造总页数或下载全部数据后切页；换仓与迟到响应隔离。
- 初次查询、空数据、读取失败及保留旧结果分别显示；出库规则查询失败不会冒充“尚未设置”。Web 环境名没有配置时不再声称“正式环境”。
- 库存列表与版本记录、当前规则与规则历史分别切换。产品对应历史进入抽屉，关闭恢复来源焦点。库存筛选有持续标签。
- 导入核对使用独立视图和可直接访问的 `import` 查询参数；浏览器返回及页面返回保留列表页、页面/表体滚动及来源焦点。发布请求期间阻止离开；回原记录时保留本次详情实例及原发布请求。刷新直达详情重新读取真实记录，列表以第一页作为回退。
- 库存、导入和发货代码在桌面使用表体滚动及可见分页；低高度、窄屏和实际放大后转为页面滚动，宽表可在表内横向查看。
- PDA 登记读取转入 IO 线程。原加密申请读取失败显示保留资料和重试读取，不显示新申请入口；继续沿用原确认、取消及完成后保存规则。
- PDA 登记、登录与订单区域互斥显示；标题栏使用设置图标，退出与高级身份维护移入独立设置页。登录字段有持续标签、密码可见性与请求防连点；已有会话明确被阻断后可重新登录，本机作业不删除。
- 设置显示原设备名称、编号、仓库、人员、环境及版本；声音开关保持原音效与持久值，连接诊断使用既有接口。退出前说明身份、资料及占用保留；后台注销失败但本机会话已清除时明确区分两项结果。生命周期取消继续向上传递。

## 失败过程与记录更正

- 前序提交 `a57a84f` 仅完成 R04 首轮，不能据其标题认定全范围收尾。原 `r04-web-orders.png` 使用双倍像素密度，不是实际 200% 缩放；原 `r04-pda-main.xml` 只有系统层级，不能证明设置页已验证，也不能单独证明被锁屏阻断。
- 先前 PC 浏览器失败与未启动服务/连接到错误库有关，没有充分证据归因于账号过期。前序 `server test bootJar` 为 UP-TO-DATE，不能算新跑了 24 项测试。
- 前序曾启动 8083 开发后台，Flyway 将本机 `acrylic_outbound_dev` 从 V10 迁至 V17；本轮浏览器准备与写操作使用隔离库，没有再次迁移、清空或还原原开发库。
- 本轮首批 23 项有 3 项失败：相同上传内容被真实去重导致测试页数不足、重复抽屉标题。后续复测还发现文本空白比较、抽屉关闭定位及自动点击前滚动导致的断言问题；保留失败日志，修正测试数据/定位及重复标题，按点击时的实际位置验证返回。
- 旧 5177 Vite 服务缓存了部分旧源码；通过读取其实际响应确认未包含最新切仓导航代码。最终改用新启动的 5178 服务，核对新源码并重跑 26 项。此前截图/通过记录不单独充当最终源码验证。
- 首次 `assembleStagingAndroidTest` 因默认只支持 Debug 原生测试而不存在；补充可选 `pdaTestBuildType=staging`，默认仍为 Debug，随后构建与真机执行成功。

## 交付边界与后续

R04 的上述源码与本机验证收尾；不是全部 Web/PDA 功能已验收。尚未进行异地升级、实际退出后重新登录的现场演练、强光人工可读性、长期作业和生产负载验收。数据大量存续的升级、完整权限/同步/任务、临时订单、换机、更正、报表及灾后恢复仍按后续路线执行。

本轮只更新开发分支，不合入 main、不打标签、不发 Release、不部署生产。Web 本机预览为 `http://127.0.0.1:5178`，连接隔离后台；公网服务未替换。R05已只读核对现有用户角色/仓库权限、离线资格、同步与持久任务实现，具体缺口见开发进度；下一实施先补用户角色/仓库授权管理入口及审计、会话失效验证，其余R05范围继续按路线执行。
